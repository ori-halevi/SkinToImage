## 1. חזון ומטרות

### הבעיה
יוצרי תוכן מיינקראפט, ובעיקר צעירים, רוצים thumbnails ותמונות עם הסקין שלהם. היום זה מחייב תוכנות מורכבות (Blender, Mine-imator, Photoshop) או תבניות בתשלום.

### הפתרון
אתר סטטי שרץ כולו בדפדפן. המשתמש מעלה סקין ומקבל מיד גלריה של תמונות PNG שקופות בפוזות ובזוויות שונות, מוכנות להורדה. בשלב מאוחר יותר יתווסף עורך thumbnail פשוט שמאפשר להשלים את כל התהליך באתר עצמו.

### מטרות
| # | מטרה | מדד הצלחה |
|---|---|---|
| G1 | מהעלאת סקין ועד תמונה ראשונה שהורדה, בפחות מ-30 שניות | זמן בבדיקות שימושיות |
| G2 | אפס עלויות תפעול | אחסון ב-GitHub Pages, בלי שרת |
| G3 | פרטיות מלאה | אף קובץ לא עוזב את הדפדפן |
| G4 | עבודה נוחה במובייל | כל זרימות ה-MVP עובדות בטלפון |
| G5 | תוצאה ברמה של thumbnail אמיתי | רזולוציה גבוהה, קצוות חדים, Outline |

## 2. קהל יעד

- **ראשי:** יוטיוברים, סטרימרים ו-TikTokers של מיינקראפט, בגילי 10–25, מכל העולם.
- **משני:** שחקנים שרוצים תמונת פרופיל, באנר לשרת Discord או סתם תמונה מגניבה.
- **מאפיינים:** מיומנות טכנית נמוכה עד בינונית, שימוש רב במובייל ובטאבלט, קשב קצר. ה-UI צריך להיות ויזואלי, מיידי ומינימלי בטקסט.
- **שפות:** אנגלית כברירת מחדל, עברית בנוסף (כולל RTL). תשתית i18n מההתחלה כדי שיהיה קל להוסיף שפות.

## 3. היקף: מה בפנים ומה בחוץ

### בפנים
- סקינים סטנדרטיים של **Java** ושל **Bedrock** בגודל **64x64**, בשני המודלים (Classic ו-Slim).
- סקינים ב-HD, כלומר כפולות של 64 (128x128, 256x256 וכו'), כל עוד הם באותה פריסת UV.
- שכבה שנייה (Overlay), כולל פיקסלים שקופים חלקית.
- טעינת סקין לפי שם משתמש Java (V2).

### בחוץ (במכוון)
- פורמט ישן 64x32.
- מודלים מותאמים של Bedrock (custom geometry), Persona, סקינים מ-Marketplace.
- גלימות (Capes) ו-Elytra. אולי בעתיד.
- שרת, חשבונות משתמש, שמירה בענן, גלריה ציבורית.
- מודלים של mobs או דמויות שאינן שחקן.

## 4. זרימות משתמש

### F1 – גנרטור מהיר (MVP)
```
דף בית → העלאת סקין (גרירה / בחירת קובץ / הדבקה)
       → זיהוי אוטומטי Classic/Slim + תצוגה מקדימה תלת-ממדית מסתובבת
       → גלריית פוזות (thumbnails נטענים בהדרגה)
       → [אופציונלי] הגדרות: זווית, Outline, גודל ראש, רזולוציה
       → לחיצה על תמונה: הורדה / העתקה ללוח / שיתוף
       → או סימון כמה תמונות והורדת ZIP
```

### F2 – כמה דמויות (V2)
```
העלאת סקין נוסף (עד 4) → מעבר ללשונית "סצנות"
       → בחירת סצנה (למשל "שניים מול שניים", "מרדף")
       → שיוך סקין לכל מקום בסצנה → הורדה
```

### F3 – עורך thumbnail (V3)
```
גלריה → "פתח בעורך" → קנבס 1280x720
       → רקע (צבע / גרדיאנט / sunburst / תמונה)
       → הזזה, הגדלה וסיבוב של הדמויות → הוספת טקסט → ייצוא PNG/JPG
```

## 6. מודל הדמות והרינדור

### 6.1 מבנה הדמות (יחידות = פיקסלי סקין)

| חלק | גודל (W×H×D) | נקודת ציר (Pivot) | Overlay inflate |
|---|---|---|---|
| Head | 8×8×8 | תחתית הראש (צוואר), גובה 24 | +0.5 |
| Body | 8×12×4 | מרכז עליון, גובה 24 | +0.25 |
| Right/Left Arm (Classic) | 4×12×4 | כתף, גובה 22 | +0.25 |
| Right/Left Arm (Slim) | 3×12×4 | כתף, גובה 22 | +0.25 |
| Right/Left Leg | 4×12×4 | ירך, גובה 12 | +0.25 |

- הטקסטורה מקבלת `NearestFilter` בלי mipmaps, כדי שהפיקסלים יישארו חדים.
- חומר השכבה השנייה מוגדר עם `transparent` ו-`alphaTest`, ומרונדר גם מבפנים (`DoubleSide`) כמו במשחק.
- **ראש מוגדל:** scale על קבוצת הראש סביב נקודת הציר של הצוואר.

### 6.2 זיהוי Slim
בודקים את ערוץ ה-alpha בפיקסל `(54, 20)` (בסקין 64x64, ובהתאם לקנה המידה ב-HD). אם הוא שקוף, הסקין הוא Slim. ההחלטה מוצגת למשתמש, והוא יכול לשנות אותה.

### 6.3 צינור הרינדור

```
Skin PNG ─► Texture ─► Character Rig (Three.js Group)
                              │
Pose JSON ───────────────────►│ apply rotations
Camera Preset ───────────────►│
Settings (big head, light) ──►│
                              ▼
          Offscreen WebGLRenderer יחיד (alpha: true, preserveDrawingBuffer)
                              ▼
                     Canvas 2D post-process
               (Outline → Shadow/Glow → Auto-trim)
                              ▼
                        Blob (PNG) + ObjectURL
```

**כללים מחייבים:**
1. **Renderer אחד לכל האפליקציה**, שמשותף לגלריה ולייצוא. דפדפנים מגבילים מספר WebGL contexts, ולכן אסור ליצור canvas תלת-ממדי לכל כרטיס.
2. **תור רינדור (Render Queue):** משימה אחת לכל frame (`requestAnimationFrame`), עם ביטול משימות שכבר לא רלוונטיות, למשל כשהמשתמש שינה הגדרה.
3. **שתי רמות איכות:** thumbnails לגלריה ב-384px (Cache לפי hash של skin+pose+camera+settings), ורינדור מלא רק כשמורידים או מעתיקים.
4. **Antialiasing:** רינדור בגודל כפול והקטנה (Supersampling), או MSAA. זה חל על הקצוות הגיאומטריים בלבד, הטקסטורה נשארת Nearest.
5. **Outline:** מסכת alpha שמורחבת (dilation) בקנבס דו-ממדי. אם הביצועים לא מספיקים ברזולוציה 4096, עוברים ל-shader של Jump Flood.
6. **Auto-trim:** סריקת bounding box של פיקסלים עם alpha > 0, ואז חיתוך עם ריפוד.

### 6.4 זיכרון
- `URL.revokeObjectURL` לכל תמונה שיוצאת מה-Cache.
- הגבלת Cache ה-thumbnails (LRU, כ-200 פריטים).
- `dispose()` לטקסטורות ולגיאומטריות כשמסירים סקין.

## 7. מודלי נתונים

### 7.1 Skin
```ts
interface Skin {
  id: string;              // uuid
  name: string;            // כינוי, משמש בשמות קבצים
  model: 'classic' | 'slim';
  modelSource: 'auto' | 'manual';
  imageBlob: Blob;         // ה-PNG המקורי
  size: number;            // 64 / 128 / 256 ...
  createdAt: number;
}
```

### 7.2 Pose
פוזות נשמרות כקבצי JSON סטטיים ב-`src/data/poses/`, כך שאפשר להוסיף פוזה בלי לגעת בקוד.
```ts
type Rot = [x: number, y: number, z: number]; // מעלות

interface Pose {
  id: string;                     // "shocked"
  nameKey: string;                // מפתח i18n: "pose.shocked"
  category: 'emotion' | 'action' | 'casual' | 'funny';
  tags: string[];
  bones: {
    head?: Rot; body?: Rot;
    rightArm?: Rot; leftArm?: Rot;
    rightLeg?: Rot; leftLeg?: Rot;
  };
  root?: { position?: [number, number, number]; rotation?: Rot };
  cameras?: CameraId[];           // זוויות מומלצות; ברירת מחדל = כולן
  heldItem?: { right?: PropId; left?: PropId }; // V2
}
```

### 7.3 Camera Preset
```ts
type CameraId = 'front' | 'threeQuarterLeft' | 'threeQuarterRight'
              | 'lowAngle' | 'faceCloseUp' | 'wideDramatic' | 'back';

interface CameraPreset {
  id: CameraId;
  fov: number;                    // 10–15 כמעט אורתוגרפי, 60+ דרמטי
  position: [number, number, number];
  target: [number, number, number];
}
```

### 7.4 Scene (V2)
```ts
interface Scene {
  id: string;
  nameKey: string;
  slots: {
    poseId: string;
    position: [number, number, number];
    rotationY: number;
  }[];                            // 2–4
  props?: { propId: PropId; position: [number, number, number]; rotation?: Rot; scale?: number }[];
  camera: CameraPreset;
}
```

### 7.5 Render Settings
```ts
interface RenderSettings {
  outline: { enabled: boolean; width: number; color: string };
  bigHead: number;                // 1.0–2.0
  lighting: 'flat' | 'shaded';
  shadow?: { enabled: boolean; offset: [number, number]; blur: number; opacity: number }; // V2
  glow?:   { enabled: boolean; color: string; size: number };                              // V2
  background: { type: 'transparent' } | { type: 'color'; color: string } /* V2 ... */;
  exportSize: 1024 | 2048 | 4096;
}
```

### 9.1 ביצועים
| מדד | יעד |
|---|---|
| טעינה ראשונית (JS gzip, בלי Composer) | ≤ 350KB |
| מהעלאת סקין ועד תצוגה תלת-ממדית | < 1 שנייה |
| 15 thumbnails ראשונים בגלריה, במכשיר בינוני | < 3 שניות |
| ייצוא בודד ב-2048px כולל Outline | < 1.5 שניות |
| ZIP של 45 תמונות ב-2048px | < 60 שניות, עם progress bar וביטול |

### 9.2 תאימות
- שתי הגרסאות האחרונות של Chrome, Edge, Firefox ו-Safari.
- iOS Safari 16+ ו-Chrome ל-Android.
- WebGL2 חובה. בלעדיו מוצגת הודעה ידידותית.
- עובד מ-360px רוחב ומעלה.

### 9.3 פרטיות ואבטחה
- **אין שליחת נתונים לשרת.** יוצא דופן יחיד: טעינה לפי שם משתמש (V2), שנשלחת לשירות צד שלישי אחרי אישור מפורש של המשתמש.
- בלי cookies ובלי analytics ב-MVP. אם יתווספו בעתיד, רק כלי שמכבד פרטיות ובלי מידע אישי.
- Content-Security-Policy דרך meta tag.

### 9.4 נגישות
- ניווט מלא במקלדת, focus נראה לעין.
- `alt` / `aria-label` לכל כרטיס פוזה (שם הפוזה בשפה הנוכחית).
- ניגודיות לפי WCAG AA.
- כיבוד `prefers-reduced-motion` (בלי סיבוב אוטומטי בתצוגה המקדימה).

### 9.5 בינלאומיות
- כל מחרוזות ה-UI בקבצי תרגום, בלי טקסט קשיח בקוד.
- `dir="rtl"` אוטומטי לעברית. בעיצוב משתמשים ב-logical properties (`ms-`, `me-` ב-Tailwind).
- זיהוי שפה אוטומטי לפי `navigator.language`, עם בורר שפה.
